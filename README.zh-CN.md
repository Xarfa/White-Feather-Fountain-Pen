## 想法

wf672 是一支本人原创的 3D 打印钢笔。在 Releases 里下载 STL 自己制作，之后的一切请自行探索。未开源的文件（说明书等）请勿向作者索要：STL 就是这个项目的全部。

白翎（wf71 等）是丹东金笔厂自 1968 年投产的自动吸水系列钢笔，其特征在于首创使用了自吸水毛细槽内芯（即「玉米棒子」结构）；wf672 复刻其经典结构，并加以改进。
