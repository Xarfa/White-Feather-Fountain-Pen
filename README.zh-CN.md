## 想法

钢笔讲究精致感，而 3D 打印做不到精致。所以 wf672 不跟这件事较劲——直接走粗野主义：裸露的层纹、外露的螺纹、原始的技术美感。书写端是买得到的标准件，其余全部可以打印、拆坏、修好、重造。

刻意完全开源。**只发 STL**——没有 CAD 源文件、没有 BOM、没有装配说明。二创、fork、打印后拿去闲鱼卖都可以，保留署名、把「wf672」这个名字留给原作就行。

**版本规则。** 小修小补升补丁号（`v1.1.1` → `v1.1.2`；这一版立住了就升次版本（`v1.1.1` → `v1.2.1`）；超稳定版（比如 `v1.5.1`）会拿去做闭源售卖，开源线则从 `v2.0.0` 重新开始。wf672 是开源线，兄弟线（wf671、wf673）各有各的节奏。
